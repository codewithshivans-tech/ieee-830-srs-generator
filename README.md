# AI SRS Document Generator (Task ID: AI-PR-004)

## 📌 Project Overview
The **AI SRS Document Generator** is an intelligent automated system designed to generate professional Software Requirements Specification (SRS) documents adhering to **IEEE 830 standards**. Developed as part of the Data Alcott Systems Free Online AI & Data Science Internship, this project streamlines requirements engineering by parsing inputs into structured documentation.

## 🛠️ Tech Stack & Requirements
* **Programming Language:** Python.
* **Document Format:** Markdown (`.md`).
* **Storage:** Lightweight JSON-based local templates (No external database required).
## 🚀 Features Implemented
* **Introduction Section Generation:** Purpose, scope, objectives, and definitions.
* **Overall Description:** User classes, operating environment, and system perspective.
* **Functional & Non-Functional Requirements:** Automated generation of core system rules and performance constraints.
* **Document Assembly:** Compiles all modular sections into a clean, standard-compliant output file.
## ⚙️ How to Run
1. Open Google Colab or any Python environment.
2. Run the provided Python generation script.
3. The system will output the final document as `SRS_Document.md`.
